Plugin WooCommerce MySargal

Points de fidelite, recompenses et cartes cadeaux automatiques sur votre boutique. Prerequis : WooCommerce installe et active. Installation en 5 minutes.

Telecharger le plugin Version 1.3.0 - MySargal • Fidelite & Cartes cadeaux
1

Recuperer votre cle API dans l'application MySargal

App MySargal › Reglages › Integrations

Ouvrez Reglages, onglet Integrations, puis appuyez sur Generer la cle API. Appuyez ensuite sur la cle pour la copier. Gardez la de cote pour l'etape 3.

Reglages
Boutique Fidelite Integrations
Votre cle
msk_live_9f3a2c8b71e4...
Appuyez pour copier
2

Installer le plugin sur WordPress

WordPress › Extensions › Ajouter

Allez dans Extensions › Ajouter › Televerser une extension, choisissez le fichier mysargal-loyalty.zip telecharge ci-dessus, cliquez Installer maintenant puis Activer.

votre-site.com/wp-admin/plugin-install.php
Extensions › Ajouter › Televerser
Fichier selectionne : mysargal-loyalty.zip
Installer maintenant
3

Coller la cle API dans le plugin

WooCommerce › MySargal

Dans le menu WooCommerce › MySargal, collez votre cle dans le champ Cle API (x-api-key). L'URL de base est deja pre-remplie, ne la modifiez pas.

votre-site.com/wp-admin › WooCommerce › MySargal
msk_live_9f3a2c8b71e4...
https://...supabase.co/functions/v1
Deja rempli, ne pas toucher
4

Activer les options et enregistrer

Meme page WooCommerce › MySargal

Verifiez que les trois options sont activees (elles le sont par defaut), puis cliquez Enregistrer.

Points de fidelite
Carte cadeau au checkout
Recompenses fidelite au checkout
Enregistrer les modifications
5

Tester une commande et une carte cadeau

Sur votre boutique

Passez une commande test : les points se creditent au paiement et la carte du client part sur WhatsApp. Puis testez une carte cadeau GC-XXXXXX directement au checkout.

Sous total 25 000 FCFA
Recompense fidelite - 5 000 FCFA
Carte cadeau GC-4B7K2P - 10 000 FCFA
Total a payer 10 000 FCFA
GC-XXXXXX
Appliquer

Bon a savoir
✓
Aucune donnee sensible n'est stockee sur votre site : tout passe par l'API MySargal via la cle x-api-key.
✓
Chaque commande ne credite les points qu'une seule fois, et une carte cadeau n'est debitee qu'une fois, meme en cas de rechargement de la page.
✓
En cas de remboursement ou d'annulation d'une commande, la carte cadeau est automatiquement recreditee.
