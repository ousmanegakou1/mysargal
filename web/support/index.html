Questions fréquentes

Comment fonctionne la carte de fidélité ?
À chaque achat, le commerçant scanne le QR code de votre carte et vous gagnez des points. Une fois le seuil atteint, vous débloquez votre récompense. Votre carte vit dans votre téléphone (lien, Apple Wallet ou Google Wallet) — rien à imprimer.
Comment vérifier le solde de ma carte cadeau ?
Rendez-vous sur mysargal.com/solde et saisissez le code de votre carte (GC-XXXXXX), ou ouvrez le lien reçu par WhatsApp. Vous y verrez le solde, l'historique et la validité.
Je suis commerçant : comment me connecter à l'application ?
Ouvrez l'application MySargal, saisissez votre numéro de téléphone, puis le code reçu par SMS. Vous accédez ensuite à votre tableau de bord : scan des clients, points, récompenses et cartes cadeaux. Pour créer un compte commerçant, écrivez-nous sur WhatsApp.
Je n'ai pas reçu mon code de connexion (OTP)
Vérifiez que le numéro saisi est correct, avec l'indicatif pays. Attendez une minute, puis réessayez. Si le problème persiste, contactez-nous sur WhatsApp et nous vous aidons à vous connecter.
Mes points ou mon solde semblent incorrects
Contactez-nous par WhatsApp ou e-mail en indiquant le nom du commerce et le code de votre carte. Nous vérifions et corrigeons rapidement.
Comment supprimer mon compte et mes données ?
Vous pouvez demander la suppression de votre compte et de vos données depuis la page Supprimer mon compte, ou en nous écrivant à support@mysargal.com.
