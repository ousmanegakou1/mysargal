Connecte ta boutique en ligne à MySargal : à chaque commande payée, ton client gagne ses points automatiquement, et sa carte Apple/Google Wallet se met à jour en temps réel. Sans plugin — juste une URL à coller.

Shopify

  1. Admin Shopify → Paramètres → Notifications → onglet Webhooks
  2. Créer un webhook : Événement = Paiement de commande (Order payment), Format = JSON
  3. URL = ton URL webhook ci-dessus → Enregistrer

C'est tout. À chaque commande payée : si le client a un numéro de téléphone, sa carte est trouvée (ou créée + envoyée par WhatsApp) et ses points sont crédités selon ta règle « 1 point = X FCFA ».

WooCommerce (WordPress)

  1. Admin WordPress → WooCommerce → Réglages → Avancé → Webhooks
  2. Ajouter un webhook : Sujet = Commande mise à jour (ou « Commande créée »), Statut = Actif
  3. URL de livraison = ton URL webhook → Enregistrer

Les commandes en statut pending / cancelled / refunded / failed sont ignorées automatiquement — pas de points sur les commandes annulées.

Odoo

Odoo se connecte via l'API MySargal, sans module à installer (Odoo auto-hébergé). Activez le mode développeur, puis Paramètres → Technique → Actions automatisées : sur le modèle Commande (sale.order) ou Point de vente, déclencheur « à la confirmation / au paiement », avec ce code :

for order in records:
    partner = order.partner_id
    phone = partner.phone or partner.mobile
    if not phone:
        continue
    requests.post(
        "https://iiocxlvcuoqafzlisqwd.supabase.co/functions/v1/api-order",
        headers={"x-api-key": "TA_CLE", "Content-Type": "application/json"},
        json={
            "phone": phone,
            "name": partner.name,
            "amount": int(order.amount_total),
            "order_id": order.name,
        },
        timeout=10,
    )

À chaque commande confirmée, les points du client sont crédités automatiquement. Pour Odoo Online (SaaS), où les appels réseau sont restreints, un petit module MySargal dédié peut être fourni sur demande.

Site custom (n'importe quel langage)

Appelle l'endpoint après chaque paiement confirmé :

curl -X POST \
  "https://iiocxlvcuoqafzlisqwd.supabase.co/functions/v1/api-order" \
  -H "x-api-key: TA_CLE" \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "+221771234567",
    "name": "Awa Ndiaye",
    "amount": 15000,
    "order_id": "CMD-2024-001"
  }'

Réponse :

{
  "success": true,
  "card_code": "LC-A1B2C3",
  "card_url": "https://mysargal.com/c/?code=LC-A1B2C3",
  "new_client": true,
  "points_added": 15,
  "total_points": 15
}

Champs

  • phone (requis) — numéro du client, avec indicatif
  • amount — montant FCFA (points calculés selon la règle de ta boutique). Sans montant : 1 commande = 1 point
  • points — pour forcer un nombre de points précis (ignore le calcul)
  • order_id — fortement conseillé : empêche tout double crédit si le webhook est rejoué

Les autres endpoints

Même authentification (x-api-key) :

Consulter un solde

POST /functions/v1/api-balance   { "card_code": "LC-A1B2C3" }

Créditer des points (scan caisse / POS)

POST /functions/v1/api-scan      { "card_code": "LC-A1B2C3", "points": 5 }

Utiliser une récompense (déduction en caisse)

POST /functions/v1/api-redeem    { "card_code": "LC-A1B2C3" }
→ { "success": true, "reward": "Café offert", "points_used": 50, "points_remaining": 10 }
→ 402 si pas assez de points (avec points_disponibles / points_requis)

Flux POS complet : api-balance renvoie reward_ready: true et la liste rewards_available dès que le client a atteint sa récompense → l'écran de caisse l'affiche → api-redeem déduit les points au moment de l'achat. La carte Wallet du client se met à jour aussitôt.

Bon à savoir

  • Tout passe en HTTPS ; les clés sont révocables à tout moment
  • Les jours « points x2 » de la boutique s'appliquent aussi aux commandes en ligne
  • Un nouveau client reçoit sa carte par WhatsApp automatiquement
  • La carte Apple/Google Wallet du client se met à jour en quelques secondes
